# 🌿 NatureQuest AI

**Less screen time. More real-world adventures.**

NatureQuest AI is a beginner-friendly open-source AI project that encourages people to spend more time outdoors through personalised nature activities.

## ✨ Features

- 🤖 Uses the open-source `google/flan-t5-small` model for AI-generated inspiration.
- 🌳 Suggests outdoor activities based on personal interests.
- ⏱️ Supports different time options, from 10 minutes to 1 hour.
- 🪴 Provides practical activity steps and nature-related benefits.
- 🛡️ Includes predefined activity plans when AI output is unhelpful.

## 🧰 Built With

- Python
- Streamlit
- Hugging Face Transformers
- Google FLAN-T5 Small
- PyTorch

## 🚀 Run Locally

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   streamlit run app.py
   ```

## 🌱 Why NatureQuest?

NatureQuest AI aims to turn screen time into an opportunity to discover the outdoors, observe local biodiversity, and develop environmentally friendly habits.

## ⚠️ Limitations

AI-generated suggestions may be inaccurate or repetitive. The application provides predefined activity steps to keep the experience useful. Always follow local safety guidance and avoid disturbing wildlife.
